## ✨ Sistema de Gerenciamento para Loja de Brinquedos
Este é um sistema para gerenciamento de cadastros e vendas em uma loja de brinquedos. 

---

## ✨ Funcionalidades Principais 

* **Cadastro e Login:** Permite o cadastro de novos clientes e o acesso restrito via login.
* **Gestão de Estoque:** Consulta e gerenciamento básico de produtos.
* **Processamento de Vendas:** Realização de transações com diferentes opções de pagamento.

---

## 🏗️ Padrões de Projeto Utilizados

O sistema foi estruturado utilizando os seguintes padrões de projeto:

### 🏭 Factory Method (Fábrica)
* **Onde é usado:** Criação de novos brinquedos/produtos.

### 🧠 Strategy (Estratégia)
* **Onde é usado:** Lógica de Compra e Pagamento.

### 👤 Singleton (Instância Única)
* **Onde é usado:** Gerenciamento da Sessão de Login (`Usuario`).
